# 📝 TO-DO LIST MANAGER (Simple CLI)

A simple command-line **To-Do List Manager** built with Python. You can **add tasks**, **delete tasks**, and **view your task list** using an interactive menu.

---

## ✨ Features
- ➕ Add tasks
- ❌ Delete tasks (by selecting task number)
- 👁️ View all tasks
- 🚪 Exit the app anytime
- Handles edge cases (e.g., deleting when list is empty)

---

## 🧰 Requirements
- Python 3.6+ (uses standard library only)

---

## ▶️ How to Run
From the project folder:

```bash
python "projects/TO_DO_List.py"
```

---

## 🕹️ Menu Options
1. **Add Task** — enter a task description
2. **Delete Task** — choose a task number to remove
3. **View Tasks** — displays all saved tasks
4. **Exit** — closes the program

---

## 📌 Example Usage
```
📝 TO-DO LIST MANAGER 📝
1. ➕ Add Task
2. ❌ Delete Task
3. 👁️ View Tasks
4. 🚪 Exit

Choose an option (1-4): 1
Enter the task description: Buy milk
✅ Task 'Buy milk' added successfully!

Choose an option (1-4): 3
📋 YOUR TO-DO LIST:
1. Buy milk

Choose an option (1-4): 4
👋 Goodbye! Have a productive day.
```
